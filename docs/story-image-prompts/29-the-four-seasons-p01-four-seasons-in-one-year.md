# Four Seasons in One Year

## Nano Banana Brief

- Story: The Four Seasons
- Page: 1
- Source text: There are four seasons in a year. They are spring, summer, fall, and winter.
- Output: 16:9 horizontal image

## Prompt

Create a children's informational picture-book illustration showing all four seasons around the same tree or landscape. Show spring blossoms, summer sun, fall red and yellow leaves, and winter snow. The four seasons should be visually distinct without using text labels.

## Continuity

Use the same educational picture-book style throughout the seasons story.

## Do Not Include

No text, captions, labels, speech bubbles, logos, watermarks, confusing season symbols, or cluttered diagram.
