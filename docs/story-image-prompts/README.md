이 폴더는 스토리 읽기 화면에 들어갈 페이지별 이미지 생성 문서 모음입니다.
각 Markdown 파일은 Nano Banana에 단독으로 전달할 수 있도록 공통 스타일, 원문, 프롬프트, 금지 조건을 포함합니다.

## 공통 출력 규칙

- 16:9 horizontal children's picture-book illustration
- Bright, warm, friendly, clear shapes
- No text inside the image
- No captions, speech bubbles, labels, UI, watermark, logo
- Same story characters should stay visually consistent across pages
- The image should clearly show the page's main noun, action, and setting
